💻 Pull Requests & Development

Here all the C programmer who want to contribute with improvement of SkollDice are welcome in my repository! I let open source ALL that I was able to produce so feel free to improve any of it and after make a merge request :)

  • Fork & Branch: Fork the repository on Codeberg/GitHub and create a descriptive feature branch (e.g., feature/entropy-boost or fix/ui-overflow).
  • Code Quality: Ensure your C backend code is clean and adheres to standard safe memory practices.
  • Testing: Test your changes locally across platforms where possible. Include verification logs if you modify the random generation engine.
  • Commit Messages: Use clear, concise commit messages outlining the exact changes made.
