🛠️ Installation & Notes

Follow these quick instructions to run your downloaded binaries securely on your local workspace:

  • Linux & macOS: Open your terminal, grant execution permission using chmod +x skolldice-bin, and run it directly or via your command line interface.
  • Windows: Extract the contents of the zip package to your preferred directory and run skolldice.exe.
