Discord Bot Setup & Commands

You can use SkollDice with the official and open-sourced bot! SkollBot!!

🤖 Quick Invite & Usage

By clicking the button below you can add the bot on your server.

Once invited, simply use standard dice notation in any channel where the bot has permissions.

The commands were created to be as handy as possible, you can write:

/roll 1d20
/r 1D20

Both commands aren't case sensitive (you can write 1D4 or 1d4) and the bot is free to use without hosting because I'm hosting it on a free VM of Oracle.

The bot accepts any sequence of Dices of the different type: D4, D6, D8, D10, D12, D20, D100. The sequences don't need a specific order.

⚙️ Self-Hosting & Configuration

Since SkollDice is fully open source, you don't have to rely on our public bot instance. You can easily host your own bot on a local machine or a cloud server.

Clone the repository from Codeberg, configure your bot token in the environment variables and compile, or you can download the entire source code in a ZIP file: inside you will find the SkollDice_bot directory.
