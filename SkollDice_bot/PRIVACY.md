# Privacy Policy for SkollDice

**Last Updated:** August 2026

## 1. General Philosophy
SkollDice respects your privacy. The bot is designed to be lightweight and transparent. We do not collect, store, or profile personal user data or private messages.

## 2. Data Handled by the Bot
To process commands and function within Discord, SkollDice handles minimal temporary data:
- **Command Inputs:** Dice roll inputs (such as dice parameters sent via commands) are processed in memory to generate the result and are not stored permanently.
- **Identifiers:** User IDs, Guild (Server) IDs, and Channel IDs are processed solely in real-time to return the command response to the correct Discord channel.

## 3. Data Storage & Retention
- **No Message Content Storage:** SkollDice does not read, log, or store chat messages outside of direct command interactions.
- **No User Profiling:** We do not track user activity, store personal metadata, or share any data with third parties.
- **No Persistent Database:** The bot does not maintain a remote database containing personal user records.

## 4. Third-Party Services
SkollDice operates via the Discord API. Any data transmitted to or from Discord is governed by Discord's Privacy Policy (https://discord.com/privacy).
