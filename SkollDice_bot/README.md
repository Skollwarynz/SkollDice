# SkollDice bot for Discord

The SkollDice script was used for the creation of its official bot for Discord. The code is open sourced to let people speriment and fork the original idea, if ever create a newer version of this bot feel free to contact me in any sort of way possible I will be glad to see the code created by me for other projects. 

### Command of the bot

The bot has only one command and the syntax is pretty simple: 

/roll  1D4 1d6 or /roll 1D4,1D6 7

The bot isn't case sensitive and don't check for a specific order for the input dices. The idea is to make the command the less complicated and fast to use as possible.

### Tecnical specification

For the programmers who'll watch the code trying to understand how it work, the idea is pretty simple. The program "main.c" uses the library Concord to acces Discord's API with ease mantaining a pretty fast and resource-firendly code. The idea of just using C as long as possible was the main reason for choosing the Concord library in the first place.
