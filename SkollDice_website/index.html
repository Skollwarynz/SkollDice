SkollDice - truly random dice generator

A fully functional dice generator that can produce real randomization when generating dice results.

⚡ The Origin & The Problem

Hello everyone, I'm a student and programmer. I started this project as a research to fix the problem with both physical and online dices.

I hear DMs that don't use specific dices or online generator because they're not really that balanced, but at the same time even physical dice can hide bubbles and have similar issues,

so for this reason I decided to create a dice generator that could truly produce randomized numbers.

💻 Open Source & Multi-Platform Vision

I then decided to set it open source and I'm currently working on distributing it on different platforms, like a free Discord bot, a desktop app and a phone app in the future.

The code is open for two main reasons, I wanted to help all the people in the world to solve this problem and let DMs and coders check if the code really does what the premise says.
